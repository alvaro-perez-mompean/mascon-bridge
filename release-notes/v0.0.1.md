最初のリリースです。

- 任意のジョイスティックやレバーのアナログ軸を、仮想の ZUIKI ワンハンドルマスコンに
  変換します。JR EAST Train Simulator はキー入力ではなく、ハンドルの絶対位置を
  読み取ります。
- ZKNS-001 系の HID ディスクリプタ、ノッチ値の表、入力レポートの組み立て
- winmm によるジョイスティック入力、キャリブレーション、軸の反転、ヒステリシス
- Windows フォームのコントロールパネルと、`list` / `calibrate` / `test` / `run` の
  コンソールモード
- ハードウェアに依存しない部分を対象とした xUnit のテスト
- タグを付けると、.NET ランタイムと HIDMaestro を同梱した自己完結型の
  Windows x64 ビルドを zip で公開します

<summary>English</summary>

First release.

- Maps an analogue axis on any joystick or lever to a virtual ZUIKI One Handle
  MasCon, so JR EAST Train Simulator reads absolute handle position instead of
  keystrokes.
- HID descriptor, notch table and report packing for the ZKNS-001 family
- winmm joystick input, calibration, inversion and hysteresis
- Windows Forms control panel, plus list/calibrate/test/run console modes
- xUnit suite over the hardware-independent logic
- Tagging publishes a self-contained Windows x64 build, .NET runtime and
  HIDMaestro bundled
