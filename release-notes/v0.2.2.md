- **ボタンとハットをウィンドウから割り当てられるようになりました。** 画面右下の
  **ボタンを設定...** を押すと、マスコンの 12 個のボタン、非常ブレーキの `EB`、そして
  ハットが並んだ画面が開きます。割り当て先を選び、手元の機器で使いたいボタンを押すだけ
  です。ハンドルの引っかかりと同じ操作で、番号を調べる必要はありません。
- **押すと置き換えではなく追加されます。** 1 つのマスコンのボタンに複数の物理ボタンを、
  別々の機器にまたがって割り当てられます。`EB` を左右どちらの親指でも押せるようにする、
  といった使い方のためです。**消す** はそのボタンの割り当てをまとめて外します。
- **初期状態では何も割り当てられなくなりました。** これまでは新しい設定ファイルに
  ボタン 1〜4 が A・B・X・Y として書かれていましたが、これは見たこともない機器についての
  推測でした。デバイス 0 がペダルだった場合、ゲーム側でドアや警笛が動いてしまい、画面には
  理由が出ません。
- **ジョイスティックの番号が変わっても追随します。** winmm の番号は接続順で決まるため、
  USB 機器を 1 つ抜き差ししただけで昨日の 2 番が今日の 1 番になります。設定ファイルに
  各番号のベンダー ID とプロダクト ID を控えるようにし、起動時に元の機器を探して、軸・
  ハット・引っかかり・ボタンの番号を書き換えます。接続されていない機器は番号をそのままに
  して、その旨を表示します。
- **保存ボタンとボタン設定ボタンに記号を付けました。** 一方はフロッピーディスク、もう
  一方はパッドのボタン 2 つです。フォントではなくコードで描いているため、環境によって
  絵文字になることがありません。
- README のスクリーンショットを現在の画面に更新しました。

ノッチ値・HID レポート・軸の読み取りには手を入れていないので、運転の操作感は v0.2.1 と
同じです。

<summary>English</summary>

- **Buttons and the hat are assigned from the window now.** **Set buttons...**, bottom
  right, opens a page with the mascon's twelve buttons, `EB` for the emergency brake,
  and the hat. Pick one, press the button you want on your hardware, done — the same
  gesture the handle catches already used, and no device numbers to look up.
- **Pressing adds rather than replaces.** One mascon button can be reached from several
  physical buttons, on different devices if you like, which is how `EB` ends up under
  either thumb. **Clear** drops all of them at once.
- **Nothing is bound out of the box.** A fresh configuration used to carry buttons 1 to
  4 as A, B, X and Y — a guess about hardware nobody had seen. If device 0 turns out to
  be your pedals, the game gets door and horn presses with nothing on screen to explain
  it.
- **The bridge follows the joysticks when Windows renumbers them.** winmm numbers by
  connection order, so unplugging any USB device turns yesterday's joystick 2 into
  today's joystick 1. The configuration now records the vendor and product id behind
  each number, finds those devices again at startup and rewrites the axis, the hat, the
  catches and every button binding. A device that is not connected keeps its number and
  is reported.
- **The save and set buttons carry a mark**, a disk and two pad buttons. Drawn in code
  rather than taken from a font, so neither turns into a colour emoji.
- The README screenshots were updated to the current window.

The notch values, the HID report and the axis reading are untouched, so it drives
exactly as v0.2.1 did.
