- **仮想デバイスの名前を変更できるようになりました。** 「仮想デバイス」の**名前**の欄に
  入力すると、その名前で名乗ります。空欄なら `mascon-bridge` のままです。ゲームはこの名前を
  見ません。Steam もゲームもベンダー ID とプロダクト ID で判定するためで、そこは変わって
  いません。
- **この欄があるのは、名前で判定する外部ソフトのためです。** たとえば BVE Trainsim の入力
  デバイスプラグインには、デバイス名でプロファイルを対応づけるものがあります。その場合は
  実機の名前を入れると一致します。ゲームで使うぶんには空欄のままで構いません。
- **Windows が覚えている名前も更新するようにしました。** Windows は各デバイスの名前を
  ベンダー ID とプロダクト ID ごとに控えていて、「ゲーム コントローラー」の画面はデバイス
  ではなくその控えを読みます。この控えが残るため、これまでは名前を変えても古いままでした。
  ブリッジは、デバイスを作る前に食い違う控えを削除し、作ったあとに正しい名前を書き込みます。
  **ブリッジを開始した時点で反映されます**（プログラムを再起動する必要はありません）。
  ただし「ゲーム コントローラー」の画面自体は自動で更新されないため、開き直してください。
- 名前が長い場合は、マウスを乗せると全体が表示されます。

ノッチ値・HID レポート・軸の読み取りには手を入れていないので、運転の操作感は v0.2.2 と
同じです。

<summary>English</summary>

- **The virtual device can be given a different name.** Type one in the **Name** box in
  the virtual device card and that is what it announces; leave it empty and it stays
  `mascon-bridge`. The game never reads it — Steam and the game both match on the vendor
  and product ids, and that has not changed.
- **The box is there for software that does look at the name.** A BVE Trainsim input
  device plugin, for instance, can map a device to a profile by name, in which case
  entering the real mascon's name is what makes the profile match. For the game, leave
  it empty.
- **The name Windows remembers is updated too.** Windows keeps a name per vendor and
  product id, and the Game Controllers panel reads that rather than asking the device.
  The entry outlives the device, which is why a new name used to have no effect. The
  bridge now clears an entry that disagrees before creating the device and writes the
  right one afterwards, so **the change lands when you press Start** — no need to
  restart the program. The panel itself does not refresh, so reopen it.
- A name longer than the box can be read from the tooltip.

The notch values, the HID report and the axis reading are untouched, so it drives
exactly as v0.2.2 did.
