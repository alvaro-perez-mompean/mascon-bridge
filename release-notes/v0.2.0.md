- **ハンドルの引っかかりを追加しました。** 実車のハンドルは両端が誤操作から守られて
  います。力行側（N から P1）は親指のボタン、非常側（B8 から EB）は押し込む必要のある
  カムです。アナログのレバーではカムの重さを再現できないため、どちらもボタンに
  置き換えました。守られているのは越えるときだけで、越えたあとは離してかまいません。
  戻ればまた掛かります。ブレーキ側が力行の引っかかりに妨げられることはありません。
  既定では両方とも無効なので、これまでどおりの操作感のままです。
- **ノッチをゲームの上に表示するオーバーレイを追加しました。** 15 のノッチを縦の
  ストリップで表示します。並びは実際のハンドルと同じで、上が非常ブレーキ、下が P5。
  マウスはそのまま通り抜けるため、ゲームへのクリックを奪いません。表示できるのは
  ゲームがウィンドウまたはボーダーレスで動いている場合だけです。
- **設定の保存先が `%APPDATA%\mascon-bridge\` になりました。** これが今回いちばん
  効く変更です。リリースはバージョン名のフォルダーに展開されるため、実行ファイルの
  隣に設定を置いていると、更新のたびにキャリブレーションも割り当ても失われていました。
  これからは展開して実行するだけです。
- **新しいバージョンが公開されるとウィンドウの左上に表示します。** ダウンロードも
  インストールもしません。リリースページへのリンクを出すだけで、ウィンドウ下部の
  チェックで切れます。
- `--config <パス>` で設定ファイルを指定できるようになりました。

## 更新するときに知っておくこと

- **以前の設定は自動で引き継ぎます。** 実行ファイルの隣にある `config.json` を初回に
  `%APPDATA%` へコピーします。元のファイルは残しますが、以降は読みません。
- **`IncludeEmergencyInAxis` は廃止しました。** EB は常にハンドルの最終位置で、
  そこへ届くかどうかは非常側の引っかかりが決めます。この項目を `false` にしていた
  場合は、14 ノッチから 15 ノッチに変わります。設定ファイルに残っていても無視されます。

<summary>English</summary>

- **Handle catches.** Both ends of the real handle are protected against being reached
  by accident: a thumb button guards N to P1, and a cam that has to be pushed past
  guards B8 to EB. An analogue lever cannot reproduce the cam's extra force, so each
  becomes a button. Only crossing is guarded — once across you can let go, and coming
  back sets the catch again. Braking is never held back by the power catch. Both are
  off by default, so the handle behaves exactly as it did.
- **An overlay that draws the notch over the game.** The fifteen notches as a vertical
  strip, laid out like the lever itself: emergency at the top, full power at the
  bottom. The mouse goes straight through it, so it never eats a click meant for the
  game. It only draws over a game running windowed or borderless.
- **The settings moved to `%APPDATA%\mascon-bridge\`.** This is the change that earns
  its place: a release unzips into a folder named after its version, so settings kept
  beside the executable were left behind by every update, calibration and bindings
  with them. Updating is now unzip and run.
- **The window says when a newer release exists**, top left, as a link to the releases
  page. Nothing is downloaded and nothing is installed, and the box at the bottom of
  the window switches the check off.
- `--config <path>` picks a different settings file.

## Before you update

- **Your settings are carried across.** A `config.json` next to the executable is
  copied into `%APPDATA%` the first time. The original is left where it was, but it is
  not read again.
- **`IncludeEmergencyInAxis` is gone.** EB is always the last position of the handle,
  and whether it can be reached is the emergency catch's business now. If you had it
  set to `false`, the handle moves from fourteen notches to fifteen. The key is
  ignored if it is still in the file.
